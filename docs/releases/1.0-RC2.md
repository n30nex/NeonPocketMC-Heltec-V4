# NeonPocketMC Heltec V4 v1.0.0 RC2

Experimental BLE companion firmware for the standard integrated-OLED Heltec WiFi LoRa 32 V4/V4.3 with SX1262.

## Included files

- `NeonPocketMC-Heltec-V4-BLE-app.bin` — normal update at `0x10000`.
- `NeonPocketMC-Heltec-V4-BLE-recovery-preserves-settings.bin` — bootloader/partition recovery at `0x0`.
- `SHA256SUMS.txt` — release hashes.
- `NeonPocketMC-Heltec-V4-v1.0.0-rc.2-source-and-licenses.zip` — exact source and retained license notices.

## Change since RC1

- Triple press returns directly to Home from any page.
- Triple press in Inbox clears every local unread message before returning Home.
- Wake-only input remains consumed while the OLED is off.
